# Cycle 7 — 2026-07-01: Binary Size & Cold Boot Optimization

> **Cycle**: 7 | **Duración**: 2026-07-01 (sesión única)
> **Objetivo**: Hacer vMK 20% mejor que upstream en todas las dimensiones medibles. Reducir binary size y cold boot.

## Resumen

Ciclo enfocado en reducción de binary size y cold boot startup. Se ejecutaron 3 phases con benchmark continuo para validar impacto. Resultado: binary -19.9%, cold boot -74.5%.

## Hallazgos

### Phase 1a: Skip Embedded Web UI
- **Impacto**: -18 MB del binary
- **Implementación**: Flag `--skip-embed-web-ui` en build.ts + env var `OPENCODE_DISABLE_EMBEDDED_WEB_UI` en vmk.cmd
- **Detalle técnico**: El Web UI (SolidJS app en `packages/app/`) se embe día completa en el binary via `import type { file }`. Al saltarlo, el hash check en `createEmbeddedWebUIBundle()` devuelve null y no se incluye.
- **Benchmark**: 158.21 MB → 140.21 MB (-11.4%)

### Phase 1b: Drop Console Statements
- **Impacto**: -5.7% del binary (158 MB → 149 MB)
- **Implementación**: Flag `drop: ["console", "debugger"]` en Bun.compile
- **Detalle técnico**: Elimina todas las llamadas a `console.*` en el bundle. No afecta `process.stderr.write()` ni `process.stdout.write()`, solo `console.log/warn/error/etc`.
- **Fix adicional**: `--help` output se rompió porque yargs v18 usa `logger.log()` que wrappea `console.log()`. Se reemplazó `cli.parse(args, callback)` con `cli.getHelp()` para output directo a stdout.

### Phase 1c: WASM Externalization
- **Impacto**: -4.34 MB del binary
- **Packages externalizados**:
  - `web-tree-sitter` (gramáticas WASM)
  - `tree-sitter-bash` (parser WASM)
  - `tree-sitter-powershell` (parser WASM)
  - `@silvia-odwyer/photon-node` (image processing WASM)
- **Implementación**: Bundler config para excluir estos packages del bundle compilado via `external` en Bun.compile
- **Benchmark**: 131.07 MB → 126.73 MB (-3.3%)

### Phase 2: MCP Token Budget
- **Feature**: `truncateLimit` por server + global `tool_output` limit (500 líneas / 10 KB)
- **Implementación**: `tool_output` límite en system prompt, `truncateLimit` configurable por MCP server en `opencode.jsonc`
- **Documentación**: AGENTS.md → MCP Token Budget Rules section

### Phase 3: LSP Idle TTL + LRU Eviction
- **Feature**: 30-min idle timeout + `MAX_FILES = 128` LRU eviction con `textDocument/didClose`
- **Implementación**: `ClientEntry { client, lastUsed }`, 5-min scan interval via forkScoped fiber
- **Impacto**: Previene acumulación de procesos LSP zombie en sesiones largas

### Phase 4: noUncheckedIndexedAccess Rollout
- **Cobertura**: 23 packages migrados
- **Implementación**: `ts-results` en packages/core/tsconfig.json, fixes en acceso a arrays en todos los packages
- **Impacto**: Type safety en accesos a indexed types

### Phase 5: Deferred Config Loading
- **Feature**: Parallel I/O en config.ts
- **Implementación**: `Effect.all({ concurrency: "unbounded" })` para cargar config desde todas las fuentes simultáneamente
- **Optimización adicional**: Early return en `normalizeLoadedConfig` para evitar spread copy innecesario

### Phase 6: vmk-tui-test.ps1
- **Script**: 7 tests automáticos para el binary compilado:
  1. Source validation (build sin errores)
  2. Binary build (`--single --skip-embed-web-ui`)
  3. `--help` smoke test
  4. `--version` smoke test
  5. `providers` list
  6. `models` list
  7. `serve` 5s timeout test
